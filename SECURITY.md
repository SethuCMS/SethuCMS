# Security policy

SethuCMS is built security-first, and we want to hear about anything that
weakens that.

## Reporting a vulnerability

Please do **not** open a public issue. Use GitHub's private reporting instead:
open the repository's **Security** tab and choose **Report a vulnerability**.

Include what you found, the steps to reproduce it, and the version. You should
get a first reply within a few days. We will fix confirmed problems before
announcing them and will credit you if you want.

## Supported versions

Only the latest 0.x release receives fixes while the project is young.

## Scope

In scope: the gateway, the admin app, the SDKs, the adapters, and the
permission, token, sign-in and webhook code. Out of scope: problems that need
control of the server or database first, and unmodified third-party services.
